# Combat Mat

Herramientas para sesiones de D&D, hosteadas en GitHub Pages con Firebase Realtime Database.

## Archivos

| Archivo | Uso |
|---|---|
| `combat-mat.html` | Mat de combate 20×20, tokens, terreno, dados 3D, multi-jugador |
| `log.html` | Overlay OBS — log de tiradas en tiempo real, fondo transparente |

## Uso

Abrir `combat-mat.html` directamente desde GitHub Pages. Todos los jugadores se conectan a la misma URL y comparten el estado en tiempo real vía Firebase.

Para el overlay OBS, agregar `log.html` como **Browser Source** con fondo transparente.

## Deploy

El proyecto se hostea en GitHub Pages directamente desde la rama `main`.
